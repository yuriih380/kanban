# Quick-start guide

[BOARD.md](BOARD.md) shows TODO, IN PROGRESS, and DONE tasks with links to their files.

[EPIC.md](EPIC.md) holds the goal, scope, acceptance criteria, and shared notes.

Each task file, such as [TSK-01.md](TSK-01.md), holds one task's status, scope, completion conditions, dependencies, and evidence. The task file owns its status; the board follows it.
