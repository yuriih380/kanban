# Quick-start guide

[quick-start-guide/BOARD.md](BOARD.md) shows TODO, IN PROGRESS, and DONE tasks with links to their files.

[quick-start-guide/EPIC.md](EPIC.md) holds the goal, scope, acceptance criteria, and shared notes.

Each task file, such as [QSG-1.md](QSG-1.md), holds one task's status, scope, completion conditions, dependencies, and evidence. The task file owns its status; the board follows it.

Each epic has a separate board folder under `kanban`. Its `EPIC.md` stores the editable board name, ticket prefix, and counter. Numbering starts at 1 per board; distinct prefixes keep full ticket IDs unique across the repository.
